# Scala・Java の書き方と Rust の対応表

この表は、Scala・Java の書き方を Rust でどう表すかについて、すでに文書に残っている決定と前例を1行ずつ並べた索引である。この表自体は新しい決定をしない。表の行と元の文書が食い違う場合は、元の文書が優先する。

各行の出どころは、文書のパスと行番号（例：`docs/goals/g0f-eventbus-and-eventstream.md:22`）か、issue・プルリクエストへのリンクで書く。決めた人は、出どころの文に書いてある人だけを書く。出どころの文に決めた人が書いていない行は「決めた人：出どころに記載なし」とする。判断待ちであることが出どころに書いてある行は、その旨を備考に書く。
