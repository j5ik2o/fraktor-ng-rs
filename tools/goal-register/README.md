# goal-register

takt manager の TUI でゴール登録を行うための、窓口側の補助スクリプトです。

ゴール登録は takt-mcp からは行えません（道具がありません）。登録は manager の
会話と確認ダイアログを通す必要があり、その操作には再現性のある手順と、
踏むと登録案が取り下げられる罠があります。このスクリプトは、その手順を
コードに固定したものです。

手順の要点（takt v0.75.0 のコードで確認済み）:

- ダイアログの初期選択は「登録しない」側です（`useRef(false)`）。
  ↑を1回押してから Enter を押します。
- 登録案が出ている間に承認以外の入力を送ると、案が取り下げられます。
  ダイアログを待つ間は、他の入力を送りません。
- 長いゴール文は、ファイルを Mac mini に置いて読み込ませる形で渡します。

使い方は `register_goal.py --help` を参照してください。登録の確認は、
最後に takt-mcp の `takt_list_goals` で新しいゴールが増えたことで行います。
想定外の状態では、スクリプトは推測で進めず、端末の表示を出して止まります。
