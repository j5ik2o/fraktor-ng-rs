triage レポートの対象ノードについて、Pekko 原典テストを Rust テストへ
移植してください。書いてよいのはテストファイルだけです。

## 置き場所と形

- 検証対象クレートの `tests/` 配下に、ノード1件＝ファイル1件で置く
  （クレート対応は knowledge `pekko-porting-rules` のとおり）
- ファイル冒頭に、出典（Pekko v1.7.1 のリポジトリ相対パス）を
  コメントで残す
- ケースは triage で数えた実数のとおり全部を移植する。ケースを
  落としたり、アサーションを弱めたりしない。どうしても移植できない
  ケースは、勝手に省かず、報告に「除外提案」として理由つきで残す

## 忠実さ

- Pekko 側のテスト名・ケース分割に対応が追える命名にする
- 時間依存（sleep や eventually 等）は、実時間待ちにせず、
  port 越しの仮想時間で書ける形を優先する。基盤がまだ無い場合は
  その旨を報告に残す
- 実装がまだ存在しない型・関数への参照は、そのまま書いてよい
  （次の verify-red でコンパイルエラーになることが想定どおりの red）

## 報告

作成したファイルパス、移植したケース数、除外提案の有無を報告して
ください。あわせて、次の3行を報告の本文に必ず含めてください
（後段の機械判定ステップがこの形式で読みます）。

```
node: {台帳のノード id}
crate: {検証対象のクレート名}
test_file: {作成したテストファイルのパス}
```
