実装が全ての機械ゲートを通ることを確認してください。
このステップでは編集しません。コマンドの実行と報告だけです。

## ゲート（すべて実行し、結果を分けて報告する）

1. `cargo test -p <対象クレート>` — 対象テストを含むクレート全体が
   通ること（対象以外の既存テストを壊していないことの確認を含む）
2. `cargo clippy -p <対象クレート> -- -D warnings`
3. `cargo fmt --check`
4. syn checker（プロジェクトの lint バイナリ）— port-adaptor 境界、
   1ファイル1公開型などの構造ルール
5. `aislop` — 変更ファイルの形状チェック

## 判定

- すべて通過 → 通過として報告する
- どれか失敗 → 失敗したゲートと、エラー出力の要点を報告する。
  自分で直そうとしない（修正は implement の仕事）

## 報告

output-contract `verify-report` の形式で、ゲートごとの合否を
表にして報告してください。
